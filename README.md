# Homebrew tap for Garner

[Garner](https://github.com/trucke/garner) is a self-hosted TV and anime manager. This tap installs `garner`, its terminal interface:

```bash
brew install trucke/tap/garner
```

`brew upgrade` brings it up to date. Each Garner release updates the cask in `Casks/` here; report problems in the [Garner repository](https://github.com/trucke/garner/issues).
